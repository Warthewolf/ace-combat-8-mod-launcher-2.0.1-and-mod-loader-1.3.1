            Modded and Unmodded

            Unmodded moves UE4SS, the Mod Loader and every mod out of the game into the mod storage folder. Play then starts the game through Steam with anti-cheat on, so online play works.

            Modded moves everything back. Play then starts the game directly with anti-cheat off, which UE4SS and the mods need. Offline and single player only.

            Modded moves everything back. Play then has Steam start the game with anti-cheat off, which UE4SS and the mods need. Offline and single player only.

            Nothing is deleted. If a switch can't finish, everything is put back the way it was.

            Adding a mod

            Drop the mod's .zip or folder onto the window, or press Add mods… on the Mods page. The launcher puts each part where it belongs. Pak mods come as .utoc and .ucas files, or as a file ending in _P.pak (text, fonts and other files the game keeps in .pak files; these need Mod Loader 1.3.1). If a download holds several versions, it asks which one you want.

            Skins made with ACE8 Skin Studio's skin slots are added in Skin Studio (Skin slots, Import), so they get a slot of their own.

            Load order

            When two mods change the same game file, only one can show: the one lower in the list. The Mods page tells you when two mods overlap and which one wins.

            A mod doesn't show up

            Check Last game start on the Play page after starting the game. Common reasons:

            • Another mod lower in the list changes the same file.
            • The .ucas file is missing next to the .utoc.
            • The game was updated, and the Mod Loader needs an update for it.
            • The game was started with Steam's Play button. While Modded, always use the launcher's Play: Steam's turns anti-cheat on, which stops the mods.
            • Steam's launch options don't have the launcher's line, so the game started with anti-cheat on. See Settings, Starting the game.
            A switch says a program has a file open

            Close the game, Explorer windows showing the game's folders, editors (VS Code, Notepad++) and command windows, then switch again.

            Linux and Steam Deck

            The game runs through Proton, so Steam has to start it. For Modded, Steam needs the launcher's line in the game's launch options (right-click ACE COMBAT 8, Properties, General, Launch Options). Settings, Starting the game, has the line, a Copy button, and Set it for me, which works while Steam is closed.

            The line runs a small script each time Steam starts the game. While Modded it starts AceCombat8.exe with anti-cheat off and tells Proton to load UE4SS. While Unmodded it does nothing, so you can leave it in.

            Steam Deck: switch between Modded and Unmodded in Desktop Mode, then play from Game Mode as usual. The launcher is in the app menu under Games, and you can add it to Steam as a non-Steam game.

            Other launch options, such as gamemoderun %command% or PROTON_LOG=1 %command%, can stay. Put the launcher's line just before %command%.

            Steam launch options, AC8_Offline.json, ac8noeac.bat

            Not needed. The launcher starts Modded without anti-cheat by itself.

            Clear the launch options in Steam (right-click ACE COMBAT 8, Properties, General) so Steam's Play button and Unmodded start the game normally. AC8_Offline.json and ac8noeac.bat can stay; the launcher doesn't use them.

            Where things are

            Pak mods: Game\Binaries\Win64\ue4ss\Mods\IoStoreLoaderMod. Script mods: ue4ss\Mods. While Unmodded they are in the mod storage folder, under "Switched off". You can choose where that folder is in Settings.

            The launcher's own settings: %LOCALAPPDATA%\ACE8 Mod Launcher.

            The launcher's own settings and the Steam launch script: ~/.local/share/ace8-mod-launcher (with Flatpak Steam: ~/.var/app/com.valvesoftware.Steam/ace8-mod-launcher for the script).
