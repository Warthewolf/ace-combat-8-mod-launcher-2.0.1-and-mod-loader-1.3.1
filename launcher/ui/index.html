              About

              Help

              Quick start
              1. Set up modding, once. On the Play page, press Set up modding. It adds UE4SS and the Mod Loader to the game folder. Then give Steam the launcher's line: Settings, Starting the game, Set it for me (with Steam closed) or Copy the line.
              2. Add a mod. Drag the mod's .zip onto this window, or press Add a mod… on the Mods page.
              3. Pick your mods. On the Mods page, switch each mod on or off. If two mods change the same thing, the lower one in the list wins.
              4. Play. Pick Modded and press Play modded. Always start a modded game here, not with Steam's Play button. To play online, pick Unmodded first.
              5. A mod didn't show up? Look at Last game start on the Play page. Still stuck: Settings, Copy support report, and send it to @voidcallsreaper on Discord.
              Can I still play online?

              Yes. Pick Unmodded and press Play unmodded. UE4SS, the Mod Loader and your mods move out of the game into the mod storage folder, and the game starts with anti-cheat on, as normal.

              Pick Modded again when you want your mods back. They come back as you left them.

              The launcher's line in Steam's launch options can stay. While Unmodded it changes nothing.

              Words you'll see
              Modded
              The game with your mods, started with anti-cheat off. Offline and single player only.
              Unmodded
              The normal game, with anti-cheat on, so online play works. Your mods wait in the mod storage folder.
              Anti-cheat
              The game's protection against cheating online (Easy Anti-Cheat). It stops mods from loading, so Modded turns it off.
              UE4SS
              A free add-on that starts with the game and runs mods inside it. Set up modding puts it in the game folder.
              Mod Loader
              Runs inside UE4SS and loads your pak mods, in the order shown on the Mods page.
              Pak mod
              The usual kind of mod: planes, skins, sounds or text. It comes as a .utoc and a .ucas file, or as a file ending in _P.pak.
              Script mod
              A mod that adds features with a small program UE4SS runs (a Lua script or a .dll). Its order doesn't matter.
              Load order
              The order pak mods load in. When two change the same thing, the lower one in the list wins.
              Last game start
              On the Play page after you play Modded: each mod as Loaded, Not loaded or Failed, and why.
              Mod storage folder
              Where your mods wait while Unmodded, and where removed mods are kept. By default "ACE COMBAT 8 - mod storage", next to the game folder.
              ~mods
              The game's own mods folder, Game\Content\Paks\~mods. The game reads it by itself too, so switching a mod there off may not stop it; Remove does.
              Removed mods
              Mods you pressed Remove on. They wait in the mod storage folder until you restore them or delete them for good.
              Launch options
              A line Steam uses when it starts the game. On Linux, the launcher's line turns anti-cheat off and loads UE4SS while Modded.
              Modded and Unmodded

              Unmodded moves UE4SS, the Mod Loader and every mod out of the game into the mod storage folder. Play then starts the game through Steam with anti-cheat on, so online play works.

              Modded moves everything back. Play then starts the game directly with anti-cheat off, which UE4SS and the mods need. Offline and single player only.

              Modded moves everything back. Play then has Steam start the game with anti-cheat off, which UE4SS and the mods need. Offline and single player only.

              Nothing is deleted. If a switch can't finish, everything is put back the way it was.

              Adding a mod

              Drop the mod's .zip or folder onto the window, or press Add a mod… on the Mods page. The launcher puts each part where it belongs. Pak mods come as .utoc and .ucas files, or as a file ending in _P.pak (text, fonts and other files the game keeps in .pak files; these need Mod Loader 1.3.1). If a download holds several versions, it asks which one you want.

              Skins made with ACE8 Skin Studio's skin slots are added in Skin Studio (Skin slots, Import), so they get a slot of their own.

              A .7z or .rar file: unpack it first, then add the folder that comes out with Add unzipped folder…, or drop it onto the window.

              Updating a mod: add the newer version the same way. It replaces the old one in place, and a script mod keeps your own settings files. If the update can't finish, the old version is put back.

              Mods on and off, and load order

              Each mod has a switch on the Mods page. Off means it stays installed but doesn't load. Changes count the next time the game starts.

              When two mods change the same game file, only one can show: the one lower in the list. The Mods page tells you when two mods overlap and which one wins. To change the order, drag a mod by its handle, or use its ▲ ▼ buttons.

              A mod tagged ~mods sits in the game's own ~mods folder, which the game also reads by itself, so switching it off may not stop it. Remove it instead.

              Removing and restoring

              Remove moves a mod to Removed mods, at the bottom of the Mods page. Its files wait in the mod storage folder. Right after removing, Undo puts it back.

              Later, Restore puts it back where it was, and Delete removes it for good. Delete asks first.

              A mod doesn't show up

              Check Last game start on the Play page after starting the game. Common reasons:

              • It's switched off on the Mods page.
              • It was added after that game start. Start the game again.
              • Another mod lower in the list changes the same file.
              • The .ucas file is missing next to the .utoc.
              • It's a .pak file whose name doesn't end in _P.pak. The Mod Loader only loads .pak files ending in _P.pak.
              • The game was updated, and the Mod Loader needs an update for it.
              • The game was started with Steam's Play button. While Modded, always use the launcher's Play: Steam's turns anti-cheat on, which stops the mods.
              • Steam's launch options don't have the launcher's line, so the game started with anti-cheat on. See Settings, Starting the game.
              A switch says a program has a file open

              Close the game, Explorer windows showing the game's folders, editors (VS Code, Notepad++) and command windows, then switch again.

              If a switch stops halfway, the Play page shows Finish switching, with a button for each mode. Nothing is lost.

              Linux and Steam Deck

              The game runs through Proton, so Steam has to start it. For Modded, Steam needs the launcher's line in the game's launch options (right-click ACE COMBAT 8, Properties, General, Launch Options). Settings, Starting the game, has the line, a Copy the line button, and Set it for me, which works while Steam is closed.

              The line runs a small script each time Steam starts the game. While Modded it starts AceCombat8.exe with anti-cheat off and tells Proton to load UE4SS. While Unmodded it does nothing, so you can leave it in.

              Steam Deck: switch between Modded and Unmodded in Desktop Mode, then play from Game Mode as usual. The launcher is in the app menu under Games, and you can add it to Steam as a non-Steam game.

              Other launch options, such as gamemoderun %command% or PROTON_LOG=1 %command%, can stay. Put the launcher's line just before %command%.

              Steam launch options, AC8_Offline.json, ac8noeac.bat

              Not needed. The launcher starts Modded without anti-cheat by itself.

              Clear the launch options in Steam (right-click ACE COMBAT 8, Properties, General) so Steam's Play button and Unmodded start the game normally. AC8_Offline.json and ac8noeac.bat can stay; the launcher doesn't use them.

              Getting help

              Copy support report copies your setup, your mods and the latest logs, with your user name left out. Paste it into a message to @voidcallsreaper on Discord. It is also in Settings, Support.

              The Mod Loader log and UE4SS log buttons (on the Play page under Last game start, or in Settings, Support) show the full logs.

              Where things are

              Pak mods: Game\Binaries\Win64\ue4ss\Mods\IoStoreLoaderMod, or the game's own Game\Content\Paks\~mods. Script mods: ue4ss\Mods. While Unmodded they are in the mod storage folder, under "Switched off". You can choose where that folder is in Settings.

              The launcher's own settings: %LOCALAPPDATA%\ACE8 Mod Launcher.

              The launcher's own settings and the Steam launch script: ~/.local/share/ace8-mod-launcher (with Flatpak Steam: ~/.var/app/com.valvesoftware.Steam/ace8-mod-launcher for the script).
