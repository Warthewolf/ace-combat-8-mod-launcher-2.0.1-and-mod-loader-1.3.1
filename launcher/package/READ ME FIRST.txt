ACE8 Mod Launcher 2.1.1 and Mod Loader 1.3.1
============================================

This download has two folders. Keep them together, side by side, as they
come out of the zip: the launcher sets up modding from the Mod Loader
folder next to it.

  ACE8 Mod Launcher   the launcher, with its README.txt
  War’s Mod Loader    UE4SS and the Mod Loader, laid out like the game
                      folder

MOST PLAYERS: USE THE ACE8 MOD LAUNCHER
  1. Unzip the download anywhere, for example in Documents.
  2. Open the ACE8 Mod Launcher folder and double-click
     ACE8ModLauncher.exe.
     If Windows says "Windows protected your PC", press "More info", then
     "Run anyway". The launcher is new, so Windows doesn't know it yet.
  3. The first time, a short tour shows you around the launcher.
  4. On the Play page, press "Set up modding". It adds UE4SS and the Mod
     Loader to the game from the War’s Mod Loader folder. You only do
     this once. If the game has them already, skip this step.
  5. Add a mod: drag the mod's .zip onto the launcher window.
  6. Pick Modded and press "Play modded".

  For online play, pick Unmodded and press "Play unmodded". Your mods wait
  in the mod storage folder until you pick Modded again.

  Help in the launcher has a Quick start and the usual fixes. The
  launcher's README.txt has the rest.

INSTALLING BY HAND INSTEAD (WITHOUT THE LAUNCHER)
  Use the "War’s Mod Loader 1.3.1" folder. Copy its Game folder into
  ...\steamapps\common\ACE COMBAT 8\ and let Windows merge the folders.
  The Mod Loader's README is in
  Game\Binaries\Win64\ue4ss\Mods\IoStoreLoaderMod\README.txt.
  Without the launcher, you need your own way to start the game with
  anti-cheat off.

Modded play is offline and single player only.
