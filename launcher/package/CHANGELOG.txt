ACE8 Mod Launcher - changelog
=============================

2.1.0 (2026-11-07)
------------------
Easier for first-time players
- A short tour shows new players around the first time the launcher finds
  the game: Modded and Unmodded, setting up modding, adding a mod, switching
  mods on and off, playing, and what to do if something goes wrong. Help >
  "Show the tour again" opens it again.
- "First steps" on the Play page ticks itself off as you go: set up modding,
  add a mod, play Modded. Each step has one button.
- Setting up modding is the first thing on the Play page of a new install.
  Adding a mod before setup offers to set up first, then adds the same mod.
- Help starts with a Quick start, and has "Can I still play online?",
  "Words you'll see", "Removing and restoring" and "Getting help".
- Plain words everywhere: the status bar, the Modded and Unmodded cards, the
  Mods page headings, and the messages for mods that don't load (what it
  means and what to do first, the technical detail after).
- Mods you just added are marked New and scrolled into view. Messages have a
  close button, and problems stay until you close them.
- While setup runs, the window shows that it is working, and afterwards it
  suggests adding a mod. Play shows "Starting..." and can't be pressed twice.
- Day theme: easier-to-read colours.

Safer with your mods
- Updating a mod that shares a folder with other mods (a ~mods folder you
  made, a pack of skins) replaces only that mod. Before, the whole folder was
  deleted, with the other mods in it.
- A different mod that happens to have the same folder name ("New mod",
  "Paks") no longer replaces yours: it is added as "Name (2)".
- Switching no longer hides your mods when some are in the game and some in
  storage (a mod put into ~mods by hand while Unmodded): the two are
  combined.
- If the launcher is closed or the PC turns off during a switch, the next
  switch finishes or undoes it properly. With the storage folder on another
  drive, a switch cut short never leaves half a copy that looks like your
  mods.
- When Steam moves the game to another library, the launcher keeps using
  your storage folder, so switched-off and removed mods don't go missing.
  "Use the default" while the storage folder can't be found no longer leaves
  your mods behind without a word.
- Moving the storage folder to another drive keeps the originals until the
  move is done, and a move that was cut short can simply be tried again.
- Restoring a removed mod puts it where it belongs for the current mode and
  never leaves the game "Half switched".
- Dropping the game's own folder is refused. Before, the game's files were
  installed as a mod.
- Only one launcher runs at a time, even when started twice quickly, and a
  busy launcher is never stopped when a newer one starts.

Adding and updating mods
- An update whose folder has a new name ("Hornet v1" to "Hornet v2") keeps
  the mod's place in the load order and its on/off state. Downloading a
  script mod again ("CoolCam (1).zip") updates it instead of adding a second
  copy that runs as well.
- A picked version is named after its download ("Su-57 Liveries - Red").
  When several downloads are added together, the launcher asks about all
  their versions before adding anything.
- LogicMods that come as .pak + .ucas + .utoc are installed whole. Pak files
  in a script mod's folder are added where the Mod Loader loads them.
- A mod that won't load as it is (a missing .ucas, a .pak mod with an old
  Mod Loader) is added with a warning saying what to do.
- Setup no longer says "Modding is set up" when UE4SS.dll is missing (some
  antivirus programs remove it). It says which file is missing.
- Dropping big folders works: no more limit of about 500 files, no double
  disk space, and a failed drop leaves nothing behind. Over 16 GB is refused.
- The Set up modding button appears as soon as the Mod Loader download is put
  next to the launcher, without restarting.

Last game start and the Mods page
- A damaged .utoc file in a mod no longer freezes the launcher.
- .pak mods in ~mods that the game loads by itself show as Loaded. A
  switched-off one says it still loads, and that Remove stops it.
- When the Mod Loader can't load .pak mods on your game version, it says so,
  instead of saying all mods loaded. Every switched-on mod file counts in
  "N of M loaded", including the ones that were skipped.
- Script mods show On or Off the way UE4SS really decides, and mods with a
  dot or an apostrophe in their name show as Started. Script errors are
  listed with the mod's name.
- Mods added after the last game start no longer show a false "Not started".
- The support report lists why mods didn't load.

Other fixes
- A failed switch keeps its reason under the switch. Quick on/off or order
  changes are no longer lost while a save is still going.
- The launcher watches up to 15 minutes for a slow game start (long Steam
  starts, shader pre-caching), and says when the game didn't start.
- If the game is on a drive that isn't connected, the launcher says so and
  offers any other copy it found, instead of switching to it for good.
- Extra launch options and the tour are saved even while the launcher is
  busy. Looking for the game no longer freezes the window, and network and
  CD/DVD drives are no longer searched.
- Error messages that start with a Japanese, Chinese or accented mod name
  are no longer garbled.
- Linux / Steam Deck: "~Mods" with other capitals is switched off too, files
  in other capitals are found, Add a mod... asks for the path when there is
  no file chooser, the Steam that has the game is used when an old one is
  left next to Flatpak Steam, and the data folder is private to your
  account.

2.0.4 (2026-11-07)
------------------
- Updating a mod overwrites the installed version in place. No copy of the
  old version goes to Removed mods any more (also for Mod Loader updates).
  If an update can't finish, the old version is put back as it was.
- Each mod on the Mods page shows when it was last updated ("Updated
  7 Nov 2026"), or when it was added.

2.0.3 (2026-11-07)
------------------
- Updating a script mod keeps what you and other mods added to it: files the
  new version doesn't have (settings saved while playing, other mods' add-ons
  in its folder) stay.
- Mods can ship an ace8-keep.txt naming files where the player's copy wins
  over the download's (for example a settings file with defaults).
- UE4SS's shared folder (ue4ss\Mods\shared) in a download is now installed,
  file by file: new files are added, changed files replace the old ones,
  and UE4SS's own shared files are never overwritten. Before, it was skipped.

2.0.2 (2026-10-29)
------------------
- "Last game start" also shows the script mods: which ones UE4SS started,
  read from UE4SS's own log, and any Lua errors it reported. It no longer
  says "No mods on" when only script mods are switched on.
- "UE4SS log" button next to "Mod Loader log".
- The support report includes the end of UE4SS's log.

2.0.1 (2026-10-22)
------------------
- "Last game start" reads Mod Loader 1.3.1's log correctly. Mods that come
  as _P.pak + .utoc + .ucas showed as "Not loaded" even though they loaded.
- Pak mods ending in _P.pak (text, fonts and other .pak files) are listed,
  ordered and switched on and off like .utoc mods. They need Mod Loader
  1.3.1, which comes with the download.
- No "install files" folder any more. Once UE4SS and the Mod Loader are in
  the game, the launcher needs nothing next to it. To install, it uses the
  Mod Loader download next to its folder ("War's Mod Loader 1.3.1"), or
  you copy that folder's Game folder into the game yourself.
- Linux and Steam Deck version (separate download). Steam starts the game
  through Proton; a line in the game's Steam launch options (the launcher
  shows it, copies it, or sets it while Steam is closed) starts it with
  anti-cheat off while Modded and unchanged while Unmodded, so Steam's own
  Play button and Steam Deck Game Mode work too.
- The Windows program no longer contains any of the Linux parts.
- Starting a new version of the launcher while an older one is still open
  closes the older one, instead of showing its window.

2.0.0 (2026-10-14)
------------------
One app for switching between Modded and Unmodded, managing your mods
and starting the game.

- Modded / Unmodded switch. Unmodded moves UE4SS, the Mod Loader and every
  mod out of the game into a storage folder next to it, so the game is
  back to how Steam installed it and online play works. Modded moves them
  back. Nothing is deleted; a switch that can't finish is undone.
- Play button. Modded starts AceCombat8.exe directly without anti-cheat
  (-eac-nop-loaded, the same as ac8noeac.bat); Steam launch options and
  AC8_Offline.json are no longer needed. Unmodded starts the game through
  Steam as normal.
- Warns you when Steam's launch options still turn anti-cheat off.
- Mods page: switch mods on and off, drag to change the load order, see
  which mods change the same game files and which one wins.
- Add mods by dropping a .zip or folder on the window. Several versions in
  one download: you choose one. An older copy of the same mod is moved to
  Removed mods.
- Remove, restore and delete mods.
- UE4SS script mods can be switched on and off.
- Installs and updates UE4SS and the Mod Loader without touching your
  settings, mods or load order. The Mod Loader's old ModLauncher.bat
  is not installed any more: the launcher's Mods page does its job.
- Shows which mods loaded the last time the game started, from the Mod
  Loader's log.
- Support report you can copy and paste into a message.
- Choose where the mod storage folder is (Settings). Everything already in
  it is moved for you.
- Switching works even while a program (an Explorer window, an editor) has
  a folder inside ue4ss open: what is inside is moved piece by piece.
- "Open in Explorer" brings the Explorer window to the front.
- Modded starts even when AceCombat8.exe is set to run as administrator:
  Windows asks for permission, and the launcher explains how to stop that.
- File and folder pickers are Windows' own dialogs. The launcher starts no
  scripts or hidden programs.
- Styled after Ace Combat's own menus, with Night, Day and Auto colours.

Any issues please contact @voidcallsreaper on Discord.
